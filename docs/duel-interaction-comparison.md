# 对局交互与卡面标识对照

对照日期：2026-09-29。依据本地 Neos 工作区、MDPRO3（`72fb92ad0`）和 YGOMobile-cn-ko-en（`9ea596c2`）源码，不代表上游最新版本。

## 当前实现

- 普通选卡、解放、等级合计采用 MDPRO3 的区域规则：候选及必选卡全部在场上、不是超量素材且能定位时直接点选；涉及手牌、墓地、卡组、素材等情况则使用列表。
- 场上点选支持单选替换、多选、必选卡锁定、合法组合高亮、确认与取消。选择条放在底部工具栏上方；选择期间禁用普通操作菜单和阶段切换。
- 场上选择与弹窗共用校验。解放使用每张卡的贡献值，等级合计支持两种数值的混合组合、必选卡和溢出合计的最少素材限制。必选卡不计入协议的可选张数限制。
- 素材定位包含 `is_overlay` 和素材序号，避免把素材选择绑定到宿主。逐张选择/取消的弹窗允许点击已经选择的素材。
- 阶段按钮采用 MDPRO3 式圆形状态盘，保留右侧 EX 区旁的位置，显示回合数、阶段名和战斗子步骤。点击展开横向六阶段节点；当前阶段金色标记，可用目的阶段亮起，不可用阶段置灰。双方回合采用蓝色/红色提示，支持回合切换动画与无卡片操作时的提示光效。阶段可用性绑定服务器当前的 idle/battle 请求；响应、新选择、回合切换或断线后清除，观战与录像不发送阶段操作。
- DP、SP、M1、BP、M2、EP 有约 650 毫秒的阶段横幅，串行消息处理等待横幅结束。已删除重复的顶部阶段消息，保留其他操作提示。
- 连锁菜单提供有可发动效果就询问模式：服务器给出合法候选时，即使 `special_count` 为 0，也等待选择；无候选自动放行。默认仍为智能连锁。

当前 Neos 的全部连锁也只在有候选时询问，因此它与新增模式在现有消息处理中的行为一致。YGOMobile 的全部时点还可以在空候选询问时弹出提示，Neos 尚未引入这项行为。动画等待只控制展示节奏，发动机会仍由协议候选和自动响应策略决定。

## 选择手续对比

此前 Neos 普通选卡、解放和等级合计直接调用有遮罩的弹窗，没有给场上卡绑定该次选择。最小化弹窗只能查看场地，不能完成选卡。本轮已为这三种手续增加场上选择。

| 手续 | Neos 当前 | YGOMobile | MDPRO3 |
| --- | --- | --- | --- |
| 普通选卡 `SELECT_CARD` | 全部在场上且非素材时直接点选，否则列表 | 场上/手牌优先点选；隐藏区域、素材或较多手牌等情况使用列表 | 全部在场上且非素材时直接点选，否则列表 |
| 逐张选择/取消 `SELECT_UNSELECT_CARD` | 场上/手牌直接点选，素材和其他区域使用列表 | 区域规则基本同普通选卡 | 全部在场上且非素材时直接点选，否则列表 |
| 解放 `SELECT_TRIBUTE` | 同普通选卡；按贡献值校验 | 场上点选，按贡献值判断可选性 | 同普通选卡；保留贡献值 |
| 等级合计 `SELECT_SUM` | 同普通选卡；动态判断合法组合 | 场上/手牌直接点选，其他区域列表 | 全部在场上且非素材时直接点选，否则列表 |
| 是否发动 `SELECT_EFFECTYN` | 是/否弹窗 | 是/否提示 | 单卡效果选择弹窗 |
| 连锁 `SELECT_CHAIN` | 经设置过滤后使用效果列表 | 经时点设置过滤，通常先询问，再点卡/选效果 | 经设置过滤后使用效果卡列表 |
| 取除指示物 `SELECT_COUNTER` | 各卡对应数字输入框 | 场上点击分配数量 | 场上点击累计数量 |
| 效果分支、宣言、排序 | 专用弹窗 | 专用界面 | 专用界面 |

多效果、不可直接点击的区域、超量素材、宣言和排序仍需要独立界面。指示物取除交互不在本轮改动范围。

## 表侧卡片标识

以下为实时叠加标识，不依赖卡图印刷内容。背面卡和超量素材不展示这些场上标识。

| 标识 | 当前实现 |
| --- | --- |
| 攻防、等级、阶级、Link 值 | 图标和数字；增加青蓝、降低红色；Link 不显示防御力 |
| 超量素材 | 叠层图标和实时数量，包含 0；素材独立变化也会刷新 |
| 指示物 | 按种类分开计数；使用通用图标，悬停看名称 |
| 灵摆刻度 | 灵摆区显示对应左右刻度，支持 0 与变化颜色；排除当作装备等情况 |
| Link 方向 | 八方向实时箭头；悬停或点击时高亮指向的合法怪兽区，处理双方视角与共享额外区 |
| 调整 | 音叉图标；后天获得调整属性时蓝色标记 |
| 属性、种族变化 | 属性用单字圆形图标，变化时蓝色标记；种族变化用通用图标，悬停显示当前种族 |
| 魔陷类别 | 通常、速攻、永续、装备、场地、反击、仪式图标 |
| 装备、持续对象关系 | 关系图标；悬停或点击相关卡显示金色实线或蓝色虚线 |
| 效果无效/不能使用 | 现有禁用图标，两种状态合并展示 |
| 操作、选择、连锁 | 保留候选/选中高亮、连锁序号和本次连锁被取对象提示 |

关系使用卡片 UUID，控制权或位置变化后继续指向同一张卡；离场、盖放、成为素材或收到取消事件会清理。连线只展示当前双方表侧场上卡。已补充关系事件和查询更新；Link 查询正确读取 Link 值及方向两个整数。

当前仍使用通用指示物图标及种族变化图标，并未复刻 MDPRO3 的全部美术资源；关系线落点使用场地位置，不逐帧跟随卡片飞行动画。
